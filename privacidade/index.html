Política de Privacidade

Contos da Lua e Lua Estúdio de Histórias · vigente desde 22 de novembro de 2026
InícioTermos de Uso

1. Resumo

O Lua Estúdio de Histórias é uma ferramenta pessoal. Ela usa apenas os dados necessários para publicar vídeos no perfil do próprio responsável e não coleta dados de seguidores, espectadores ou de qualquer outra pessoa.

2. Dados tratados

Quando o responsável autoriza a ferramenta na tela oficial do TikTok, o TikTok fornece:

  • informações básicas do perfil autorizado (identificador da conta, nome de usuário e foto), escopo user.info.basic;
  • chaves de acesso temporárias que permitem publicar vídeos nesse perfil, escopo video.publish.

3. Como os dados são usados

Exclusivamente para publicar, no horário programado, os capítulos aprovados pelo responsável e para consultar se a publicação foi concluída. Os dados não são vendidos, compartilhados com terceiros nem usados para publicidade.

4. Onde ficam guardados

As chaves de acesso ficam armazenadas apenas no computador do responsável, em arquivo protegido, e não em servidores de terceiros. Elas são enviadas somente ao próprio TikTok, pela conexão criptografada da API oficial.

5. Por quanto tempo

As chaves expiram automaticamente segundo as regras do TikTok. Ao desconectar a conta na ferramenta, ou revogar o acesso nas configurações do TikTok, as chaves deixam de funcionar e são apagadas do computador do responsável.

6. Este site

Este site não usa cookies, formulários nem ferramentas de análise. Ele é hospedado no GitHub Pages, que pode registrar dados técnicos de acesso conforme a política de privacidade do GitHub.
